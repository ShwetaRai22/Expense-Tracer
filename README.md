# 💰 Expense Tracker

A simple and responsive Expense Tracker built using HTML, CSS, and JavaScript.

This project allows users to record their expenses, manage their income, track their balance, and view spending statistics. Data is stored in the browser using LocalStorage, so it remains available even after refreshing the page.

## 🚀 Live Demo

[View Expense Tracker](https://shwetarai22.github.io/Expense-tracer/)

## 📌 Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Filter expenses by category
- Add and track total income
- Calculate total expenses
- Calculate remaining balance
- Calculate average daily expense
- Calculate average monthly expense
- Store expenses using LocalStorage
- Store income using LocalStorage
- Data persists after page refresh
- Responsive and user-friendly interface
- Lucide icons for a cleaner UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Lucide Icons
